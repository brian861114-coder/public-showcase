文章不只是文字。這一頁示範三種常見內容形態。

## 1. 圖片

把檔案放到 `public/images/`，然後這樣引用：

![淺色示意插圖](/images/sample-illustration.svg)

## 2. 短片（mp4）

把演示影片放到 `public/videos/demo.mp4` 後，在後台插入「短片（mp4）」元件，或直接寫：

<Video src="/videos/demo.mp4" poster="/images/sample-illustration.svg" />

建議長度控制在數秒到十數秒，檔案不要太大，比較適合 GitHub Pages。
